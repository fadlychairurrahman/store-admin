# 🛒 Admin Store — Aplikasi Manajemen Produk, Stok, dan Pembelian

Admin Store adalah aplikasi web sederhana berbasis **Node.js (Express)** dan **MySQL** yang digunakan untuk mengelola data produk, stok, dan pembelian pada toko/barbershop.

Didesain dengan **Bootstrap 5** agar tampilan rapi dan mudah digunakan.

---

## 🚀 Fitur Utama

✅ **Manajemen Produk**
- Tambah, edit, dan hapus data produk  
- Menyimpan nama, harga, dan deskripsi

✅ **Manajemen Stok**
- Tambah dan ubah jumlah stok setiap produk  
- Data stok otomatis terhubung dengan produk

✅ **Manajemen Pembelian**
- Input pembelian produk beserta jumlah dan total harga  
- Status pembelian otomatis menjadi `selesai`  
- Bisa ubah status pembelian menjadi `cancelled`

✅ **Tampilan Responsive**
- Menggunakan **Bootstrap 5**  
- Bisa dibuka dari laptop maupun smartphone
